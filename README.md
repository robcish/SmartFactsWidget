# Smart Facts Widget

A calm, minimalist Android app and widget that delivers short educational facts each day — directly to your home screen.

Built with **Jetpack Compose**, **Glance**, **Room**, and **Firebase**.
Offline-ready, ad-free, designed for simplicity.

---

### ✨ Features
- 🧠 Daily educational facts across multiple topics
- 🪶 Clean UI with light/dark themes
- 🗂️ Widget-first design (Glance)
- 🔄 Auto-update & caching (WorkManager + Room)
- 📴 Works offline (prefetched content)
- 🧩 Built with Compose architecture principles

---

### 🧱 Tech Stack
- **Kotlin**
- **Jetpack Compose**
- **Glance AppWidget**
- **WorkManager**
- **Room**
- **Firebase Firestore (read-only)**
- **Hilt / DI**
- **Material 3**

---

### 🌿 Project Goal
A personal portfolio project focused on clean architecture, simple UX, and non-commercial educational value.

> “No ads. No noise. Just knowledge.”
