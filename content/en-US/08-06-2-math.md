Published by Henry Gordon Rice in 1953, this theorem dramatically extends the halting problem. It states that for **any** non-trivial property of the function computed by a program — whether it produces output, whether it's equivalent to another program, whether it ever enters a certain state — no general algorithm can decide it.

A property is "non-trivial" if it's true for some programs and false for others. The only decidable properties are the trivial ones: those true for all programs or none. This means all interesting questions about program behavior are fundamentally unanswerable in general.
