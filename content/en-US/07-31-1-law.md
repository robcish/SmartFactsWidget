When Microsoft ended **SHA-1** code signing support for Windows Update, it showed that security decisions are not only technical but also **policy decisions**. Software vendors, certificate authorities, and regulators all have to decide how long old cryptographic systems remain acceptable. In practice, trust on the internet is governed by rules as much as by math.
