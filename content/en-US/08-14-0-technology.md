Go emerged in **2009** from frustration with slow C++ compile times at Google. Its creators — **Ken Thompson** (co-creator of Unix, UTF-8, and B language) and **Rob Pike** (Plan 9, UTF-8) — deliberately designed it to be boring: no classes, no inheritance, no exceptions, minimal syntax.

The language's killer feature is built-in **concurrency** through goroutines — lightweight threads that cost just a few kilobytes of memory each. A single Go program can easily run millions of concurrent goroutines. This made it the default language for cloud infrastructure: Docker, Kubernetes, and Terraform are all written in Go.
